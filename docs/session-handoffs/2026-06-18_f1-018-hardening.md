1. Harness reduzido de 41→18 skills, 35→20 agents (8 core + 12 domain)

3. Freshness real calculada via mtime Bronze (substituiu `0.0` hardcoded)
4. CI com `--cov-fail-under=60` + job security (Bandit + Safety)
